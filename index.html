Fiches pédagogiques du CP1 au CM2, pour les instituteurs de Côte d'Ivoire

Le Cahier de l'instituteur

Des fiches pédagogiques prêtes, pour tous les niveaux et toutes les matières du primaire.

L'instituteur choisit un niveau, une matière, une leçon puis une séance. L'application construit la fiche complète — objectifs, situation d'apprentissage, déroulement, évaluation — en suivant les programmes officiels, puis l'exporte en fichier Word. Un dictionnaire, un conjugueur et un générateur d'exercices complètent l'ensemble.

Installer l'application

L'application n'est pas sur le Play Store : elle est distribuée directement en fichier APK, ici même. L'installation prend deux minutes.

  1. Toucher le bouton « Télécharger l'APK » ci-dessus, depuis le téléphone.
  2. Ouvrir le fichier téléchargé, depuis les notifications ou le dossier Téléchargements.
  3. Si le téléphone le demande, autoriser « Installer les applications inconnues » pour le navigateur utilisé.
  4. Toucher Installer, puis ouvrir Le Cahier de l'instituteur.

Un message peut avertir que l'application vient d'une source inconnue de Google. C'est normal pour toute application installée hors Play Store — cela ne signifie pas qu'elle est dangereuse. Toucher « Installer quand même » pour continuer.
