Une fiche en quatre gestes

Le déroulement suit les guides pédagogiques officiels et les manuels en usage dans les écoles.

  1. Choisir la classe

    Du CP1 au CM2, et l'édition du manuel que vous utilisez.

  2. Choisir la leçon

    Matière, leçon puis séance, rangées comme dans votre progression.

  3. Relire et corriger

    La fiche s'affiche en tableau. Vous modifiez le texte de chaque case si besoin.

  4. Imprimer ou partager

    Un document propre, avec l'en-tête rempli, prêt pour le cahier de préparation.

Activation par niveau

Un code débloque un niveau (par exemple CM2) sur votre téléphone. Pour l'obtenir :

  1. Ouvrez l'écran Activation dans l'application.
  2. Envoyez par WhatsApp votre numéro d'appareil et le niveau voulu.
  3. Saisissez le code reçu : le niveau est débloqué.

Installer en deux minutes

L'application est distribuée directement ici, sous forme de fichier APK. Elle fonctionne sur tous les téléphones Android récents : Tecno, Infinix, itel, Samsung et les autres.

  1. Depuis le téléphone, touchez Télécharger pour Android. Le fichier arrive en quelques secondes.
  2. Ouvrez le fichier : depuis la notification « Téléchargement terminé », ou dans Fichiers > Téléchargements.
  3. Android demande d'autoriser les applications inconnues. Activez l'interrupteur, puis touchez Retour.
  4. Touchez Installer, patientez quelques secondes, puis Ouvrir.

Un message peut indiquer que l'application est inconnue de Google. C'est le cas de toute application installée hors Play Store, cela ne veut pas dire qu'elle est dangereuse. Touchez « Installer quand même ».

En cas de souci

Le bouton Installer reste grisé
L'interrupteur de l'étape 3 n'est pas activé. Revenez en arrière et activez-le.
Je ne trouve pas le fichier
Ouvrez Fichiers (ou Gestionnaire de fichiers), puis Téléchargements, puis cahier-instituteur.apk.
« Application non installée »
Souvent, le téléchargement a été interrompu ou le téléphone manque d'espace. Supprimez le fichier, libérez de la place (au moins 300 Mo), retéléchargez-le avec une bonne connexion, puis recommencez.
Toujours bloqué ?
Écrivez-nous sur WhatsApp avec une capture de l'écran : nous vous aidons à finir l'installation.

Questions fréquentes

Faut-il une connexion internet ?
Oui pour préparer une fiche : l'application la rédige en ligne, une connexion mobile ordinaire suffit. Le dictionnaire et le conjugueur fonctionnent sans internet.
Les fiches respectent-elles les programmes officiels ?
Oui. Elles sont construites à partir des guides pédagogiques et des manuels utilisés en Côte d'Ivoire, avec le déroulement attendu à chaque niveau.
Puis-je modifier une fiche ?
Oui. Avant l'impression, la fiche s'affiche en tableau et vous pouvez changer le texte de chaque case pour l'adapter à votre classe.
J'enseigne dans une classe à double niveau
Activez les deux niveaux : chaque code débloque un niveau sur votre téléphone.
Comment obtenir les mises à jour ?
Quand une nouvelle version sort, l'application vous prévient. Il suffit de retélécharger l'APK depuis cette page et de l'installer par-dessus : vos fiches et vos classes sont conservées.
Que deviennent mes données ?
Elles servent uniquement au fonctionnement de l'application. Le détail figure dans la politique de confidentialité.
