VOTRE CODE DANS L'APPLICATION

Quatre étapes, sans difficulté

L'application étant installée directement depuis cette page (hors Play Store), le code n'est pas transmis automatiquement : copiez-le maintenant, puis collez-le dans le formulaire.

  1. Copiez le code

    Touchez « Copier le code » ci-dessus. Vous pouvez aussi copier le lien entier : l'application le reconnaît.

  2. Installez l'application

    Touchez « Télécharger pour Android », ouvrez le fichier, autorisez l'installation puis touchez « Installer ».

  3. Ouvrez « Je veux m'abonner »

    Dans l'application : menu ☰ en haut à gauche, puis Paramètres & Activation, puis Je veux m'abonner.

  4. Collez le code au champ 5

    Au champ 5. CODE DE PARRAINAGE, touchez l'icône Coller (ou maintenez le doigt dans le champ puis « Coller »). « Code valable » s'affiche : envoyez votre demande.

Le formulaire « Je veux m'abonner » est disponible à partir de la version 1.5.2 de l'application. Si vous ne le trouvez pas, téléchargez la dernière version depuis cette page.

CE QUE FAIT L'APPLICATION

Un assistant pensé pour votre quotidien

  • Fiches de leçon

    Conformes aux programmes officiels ivoiriens, prêtes en quelques minutes, en PDF.

  • Mes classes

    Listes d'élèves, registre d'appel, journal de classe et documents administratifs.

  • Notes et résultats

    Saisie rapide, moyennes et classements, relevés de notes.

  • Planification

    Emploi du temps officiel, programme et répartition mensuelle.

  • Outils du maître

    Dictionnaire, conjugueur, conversions et banque d'exercices.

  • Hors connexion

    Les saisies de classe sont gardées sur le téléphone et envoyées au retour du réseau.
