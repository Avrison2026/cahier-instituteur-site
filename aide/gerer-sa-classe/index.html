1. Où se trouve la gestion de classe ?

Tout part du bouton Mes classes, en bas de l'écran. Vous y trouvez votre classe, et quatre raccourcis pour le travail de tous les jours.

L'écran « Mes classes » :

ZoneCe qu'on y trouve
Carte de la classeNom, année, nombre d'élèves ; boutons Élèves et Fiche
Prochain coursLe prochain cours de l'emploi du temps, avec Préparer
Au quotidienRegistre d'appel, Journal de classe, Suivi des élèves, Résultats
Ressources du niveauExercices, Proposition de sujets, Banque de dictées

L'écran « Détail de la classe » s'ouvre quand vous touchez la carte de la classe (ou son bouton Élèves). Il a trois onglets :

OngletÀ quoi il sert
ÉlèvesLa liste des élèves : ajouter, modifier, rechercher
OutilsSaisie des notes, résultats, composition mensuelle, matières et barèmes, registre d'appel, statistiques, groupes d'EPS
DocumentsTous les documents à imprimer : liste, tableau récapitulatif, résultats, kits, manuels, import Excel

Ce tutoriel suit l'ordre d'une année : créer la classe, inscrire les élèves, faire l'appel, saisir les notes, imprimer les résultats.

2. Étape 1 : créer votre école et votre classe

Cela se fait une seule fois par année scolaire.

A. Ajouter votre école (si l'application vous le demande)

  1. Touchez Mes classes, puis + Ajouter en haut. Tant que vous n'avez pas d'école, ce bouton ouvre la fenêtre « Ajouter une école » (pour une deuxième école : trois points en haut à droite, puis Ajouter une école).
  2. Nom de l'école : écrivez-le en entier, par exemple EPP Alla Lamine 1. Ce nom sera imprimé sur vos fiches et vos documents.
  3. Année scolaire : vérifiez qu'elle est juste, par exemple 2026-2027.
  4. Touchez Ajouter.

B. Ajouter votre classe

  1. Dans Mes classes, touchez + Ajouter en haut. La fenêtre « Ajouter une classe » s'ouvre.
  2. Si vous avez plusieurs écoles, choisissez la bonne dans École.
  3. Dans Niveau, touchez votre niveau (CP1, CP2, CE1, CE2, CM1, CM2, ou une section de maternelle).
  4. Nom de la classe : par exemple CM2 A. Si vous le laissez vide, la classe prend le nom du niveau.
  5. Année scolaire : vérifiez-la.
  6. Touchez Ajouter.

La classe apparaît dans Mes classes. Elle est enregistrée sur votre téléphone, même sans connexion, puis sauvegardée en ligne dès que vous avez du réseau.

Vous avez plusieurs classes ? Répétez l'étape B pour chacune. Pour changer le nom ou l'année d'une classe : ouvrez-la, touchez les trois points en haut à droite, puis Modifier la classe.

3. Étape 2 : inscrire vos élèves

Vous avez deux façons de faire. Choisissez celle qui vous arrange.

Façon 1 : un par un, sur le téléphone

  1. Dans Mes classes, touchez votre classe. L'écran « Détail de la classe » s'ouvre, sur l'onglet Élèves.
  2. Touchez + Ajouter.
  3. Remplissez la fiche de l'élève. Seuls le Nom et les Prénoms sont obligatoires. Remplissez aussi, si possible : Genre, Date de naissance (l'âge se calcule tout seul), Lieu de naissance, Matricule, Nationalité, Nom du parent, Contacts, Scolarité (années), Conduite.
  4. Touchez Ajouter. Recommencez pour l'élève suivant.

Façon 2 : toute la liste d'un coup, avec Excel (pratique si vous avez un ordinateur)

  1. Ouvrez votre classe, puis l'onglet Documents.
  2. Touchez Télécharger le modèle Excel vierge.
  3. Remplissez ce fichier : une ligne par élève, sans changer les titres des colonnes.
  4. Revenez dans Documents et touchez Importer depuis Excel. Choisissez votre fichier.
  5. Un aperçu s'affiche. Vérifiez les noms, puis confirmez l'import.

Une fois la liste faite :

  • Les élèves sont classés par ordre alphabétique, l'ordre officiel des listes et des relevés.
  • Les noms des filles s'affichent en rouge.
  • Pour voir aussi les contacts et la conduite : touchez Organiser, puis Afficher contacts et conduite.
  • Pour modifier ou supprimer un élève : touchez les trois points à droite de son nom, puis Modifier ou Supprimer.
  • Pour chercher un élève : utilisez la barre Rechercher un élève.

Pourquoi bien remplir les fiches ? Le genre, la date de naissance et la scolarité servent à remplir automatiquement le tableau récapitulatif et les statistiques (filles, garçons, âges).

4. Étape 3 : faire l'appel chaque jour

Le registre d'appel remplace le registre papier. Il fonctionne sans connexion internet.

Ouvrir le registre : dans Mes classes, touchez la tuile Registre d'appel (rubrique « Au quotidien »).

Faire l'appel du jour :

  1. L'onglet Appel du jour s'ouvre sur la date d'aujourd'hui.
  2. Par défaut, tous les élèves sont présents. Vous ne notez que les absents.
  3. Pour un absent, touchez la case à droite de son nom. Une petite fenêtre s'ouvre.
  4. Cochez Absent le matin, Absent l'après-midi, ou les deux. Touchez Enregistrer.
  5. Quand tous les absents sont notés, touchez Valider l'appel en bas de l'écran. Le message « Appel validé » s'affiche.

Les signes dans les cases (comme sur le registre papier) :

SigneSignification
−Absent le matin
|Absent l'après-midi
+Absent toute la journée

Corriger une erreur : touchez de nouveau la case de l'élève et décochez. Si vous décochez tout, l'absence est effacée.

Un autre jour : utilisez les flèches ‹ › à côté de la date pour revenir sur un jour passé. Un jour peut être marqué Jour férié ou Vacances : il ne compte plus dans les calculs.

En haut de l'écran, trois boutons :

  • Élèves : enregistrer les entrées et sorties d'élèves en cours d'année.
  • Bilan : le taux de présence du mois, le nombre de demi-journées d'absence et les élèves à surveiller (présence sous le seuil).
  • Imprimer : le registre du mois en PDF, prêt à signer.

L'onglet Vue du mois montre tout le mois d'un coup d'œil, élève par élève.

5. Étape 4 : saisir les notes

Avant la première composition, vérifiez vos matières (une seule fois) :

  1. Ouvrez votre classe, onglet Outils, puis Matières et barèmes.
  2. Vous voyez les matières officielles du niveau et leur total (par exemple Dictée sur 20, Mathématiques sur 50).
  3. Si votre école fait autrement, vous pouvez ajouter une matière, en retirer une, ou changer son total. Enregistrez.

Ce réglage vaut pour cette classe seulement, pour les compositions et les compositions mensuelles.

Saisir les notes d'une composition :

  1. Ouvrez votre classe, onglet Outils, puis Saisie des notes.
  2. En haut, choisissez l'évaluation : Compo. 1, Compo. 2, Compo. 3, Passage, ou Mois (composition mensuelle). La date officielle de la composition s'affiche dessous.
  3. Choisissez votre façon de saisir :
    • Par matière : toute la classe en Dictée, puis toute la classe en Mathématiques… (le plus rapide avec les copies rangées par matière) ;
    • Par élève : toutes les matières d'un élève, puis l'élève suivant.
  4. La case de l'élève en cours est encadrée. Tapez la note sur le clavier de l'écran (la touche ,5 ajoute un demi-point).
  5. Touchez Suivant : la note est enregistrée et la case suivante s'ouvre. Passer laisse la case vide pour plus tard.

Bon à savoir :

  • Une note au-dessus du total (par exemple 23 sur 20) est refusée, avec un message.
  • Pour corriger, touchez la case de l'élève, effacez avec la touche ⌫, puis tapez la bonne note.
  • L'écran indique combien de notes sont saisies (par exemple « Dictée · 8 / 14 notés »).
  • Sur ordinateur (version Web), la saisie se fait dans un grand tableau élèves × matières : tapez la note puis Entrée pour passer à l'élève suivant, Tab pour la matière suivante.

6. Étape 5 : résultats, moyennes, rangs et documents à imprimer

Vous n'avez rien à calculer : dès que les notes sont saisies, l'application calcule les moyennes et les rangs.

Voir les résultats d'une composition :

  1. Ouvrez votre classe, onglet Outils, puis Résultats des compositions (ou la tuile Résultats dans Mes classes).
  2. Choisissez la composition en haut.
  3. Vous voyez la moyenne de la classe, la plus forte et la plus faible moyenne, et le nombre d'élèves ayant la moyenne.
  4. Dessous, la liste des élèves avec leur moyenne et leur rang. Le bouton Par rang / A → Z change l'ordre.

Imprimer ou partager le tableau de la classe : touchez Exporter (pour imprimer) ou Partager (pour l'envoyer), puis choisissez PDF (pour imprimer ou envoyer) ou Excel (pour retravailler le tableau).

Envoyer son résultat à un parent :

  1. Dans la liste, touchez l'élève.
  2. Sa fiche de résultat s'affiche (notes, moyenne, rang, observation).
  3. Touchez Au parent : WhatsApp s'ouvre avec un message prêt et le PDF du résultat joint. Le visa des parents est toujours imprimé sur le document.

Composition mensuelle : Outils → Composition mensuelle donne les notes du mois, les moyennes, les rangs et les observations. Elle ne compte pas dans la moyenne générale de l'année.

Envoyer les résultats au directeur : dans votre classe, touchez les trois points en haut à droite, puis Envoyer les résultats au directeur (PDF). Le même menu permet d'exporter toutes les notes en Excel, PDF ou Word.

Le relevé d'un élève : onglet Élèves, trois points à droite de son nom, puis Relevé de notes.

Les statistiques : Outils → Statistiques de la classe montre la moyenne générale et son évolution au fil des compositions.

Les autres documents de la classe sont dans l'onglet Documents :

DocumentContenu

7. Étape 6 : les autres outils de la classe

L'emploi du temps

  • Où : sur l'Accueil, rubrique Outils pédagogiques, puis Emploi du temps.
  • Il est déjà rempli pour votre niveau. Choisissez le jour en haut (Lundi, Mardi, Jeudi, Vendredi) ; touchez une ligne pour la modifier, ou + Ajouter une ligne.
  • Il sert partout : la carte « Ma classe aujourd'hui » de l'Accueil, le « Prochain cours », la remédiation PNAPAS.

Le journal de classe

  1. Dans Mes classes, touchez la tuile Journal de classe.
  2. Dans Préparer la semaine, choisissez le niveau et la semaine.
  3. Le contenu de la semaine s'affiche jour par jour, déjà rempli d'après le programme. Touchez le crayon pour modifier une ligne.
  4. Touchez Générer le PDF ou Word : le journal est prêt à imprimer.

Les groupes d'EPS

  • Où : votre classe, onglet Outils, puis Groupes d'EPS.
  • Touchez Créer un groupe : donnez-lui un nom et une couleur, puis choisissez ses élèves. Dans chaque groupe, vous pouvez créer des équipes et désigner un capitaine. La liste « Élèves sans groupe » montre ceux qui restent à placer.
  • Exportez en PDF ou Word : une grande feuille lisible à afficher au terrain.

La distribution des kits et les manuels PNAPAS

  1. Votre classe, onglet Documents, puis Distribution des kits (ou Gestion des manuels PNAPAS).
  2. Cochez les élèves qui ont reçu leur kit ou leur manuel ; notez le nom du parent (et l'état du manuel).
  3. Produisez le document en PDF, Word ou Excel, avec une colonne pour l'émargement des parents.

La cantine et les activités extra-scolaires

  • Sur l'Accueil, rubrique Gestion quotidienne, touchez Ajouter mon activité extra-scolaire, puis choisissez Cantine (ou une autre activité).
  • Une carte apparaît ensuite sur l'Accueil pour la saisie de chaque jour (rationnaires, plat du jour, stocks, résultats).

Le calendrier scolaire officiel

  • Sur l'Accueil, la carte Ma classe aujourd'hui rappelle la prochaine composition et les prochains congés. Touchez-la pour voir tout le calendrier de l'année (compositions, examens, vacances).

8. Questions fréquentes

Je n'ai pas de connexion internet. Mes saisies sont-elles perdues ?
Non. La classe, les élèves et le registre d'appel sont enregistrés sur le téléphone, puis sauvegardés en ligne dès que le réseau revient.

Je ne vois pas « Saisie des notes » dans les Outils.
Les outils de notes n'apparaissent pas pour les classes de maternelle. Pour les autres niveaux, vérifiez que vous avez ouvert la bonne classe.

Une note est refusée.
Elle dépasse le total de la matière (par exemple 23 sur 20). Vérifiez la copie, ou changez le total dans Matières et barèmes si votre école note autrement.

Les moyennes ne bougent pas après une correction.
Le message « Résultats à recalculer » peut s'afficher : les notes sont à jour, les moyennes et les rangs se mettent à jour juste après.

J'ai supprimé une classe par erreur.
Dans Mes classes, touchez les trois points en haut à droite, puis Corbeille : la classe peut être restaurée pendant un temps limité.

Un nouvel élève arrive en cours d'année.
Ajoutez-le dans l'onglet Élèves (étape 2), puis, dans le registre d'appel, bouton Élèves, notez sa date d'entrée : il ne sera pas compté absent les jours d'avant.

Où retrouver un document déjà produit ?
Dans votre classe, onglet Documents, puis Mes documents : tous les documents produits sur ce téléphone pendant 30 jours.

Une autre question ?
Dans l'application : Réglages → Nous contacter.
