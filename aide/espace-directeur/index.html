1. C'est quoi, l'Espace Directeur ?

L'Espace Directeur permet au directeur d'une école de suivre toutes les classes de son établissement depuis son téléphone : effectifs, résultats, journaux de classe, documents administratifs.

Ce que le directeur peut faire :

  • voir les effectifs de l'école (filles, garçons, redoublants), niveau par niveau ;
  • suivre les résultats des compositions et l'avancement de la saisie des notes ;
  • viser les journaux de classe envoyés par les enseignants ;
  • préparer la Fiche 4, le PACC et le rapport mensuel, en PDF ou Word ;
  • recevoir les documents envoyés par les enseignants (listes, résultats, journaux, fiches du personnel).

Ce que le directeur ne peut pas faire : modifier les notes ou les élèves d'un enseignant. Tout est en lecture seule, et seulement pour les classes dont l'enseignant a donné son accord.

Qui l'utilise ?

QuiCe qu'il fait dans l'Espace Directeur
Le directeur (ou la directrice)Demande le rôle, puis suit son école
Chaque enseignant de l'écoleRattache sa classe à l'établissement et envoie ses documents

Où le trouver ? Sur l'Accueil, touchez les trois points en haut à droite (Menu), puis Espace Directeur. Vous pouvez aussi taper « Directeur » dans la barre de recherche de l'Accueil.

2. Étape 1 (directeur) : demander le rôle Directeur

Le rôle n'est pas automatique : le concepteur de l'application vérifie chaque demande avant de l'accorder. C'est ce qui protège les données de votre école.

Préparez avant de commencer l'une de ces deux preuves :

  • votre avis de nomination (vous allez le photographier) ;
  • ou le nom et le numéro de téléphone de votre conseiller pédagogique, qui confirmera que vous dirigez l'école.

Envoyer la demande :

  1. Ouvrez l'Espace Directeur (Accueil → trois points → Espace Directeur).
  2. Dans la carte « Vous dirigez une école ? », touchez Demander le rôle Directeur.
  3. Remplissez le formulaire :
    • Civilité et Nom et prénoms ;
    • Nom officiel de l'établissement, par exemple EPP LES PALMIERS 1. Un groupe scolaire comprend souvent plusieurs EPP : indiquez celle que vous dirigez ;
    • Code administratif (facultatif, mais il évite les doublons) et Groupe scolaire (facultatif) ;
    • DRENA, IEPP, Localité et Année scolaire.
  4. Dans Preuve de votre fonction (obligatoire), choisissez :
    • Photo de mon avis de nomination : touchez Prendre la photo (ou Choisir dans la galerie). La photo doit être lisible : nom, école, signature. Elle est supprimée après la vérification ;
    • ou Mon conseiller pédagogique peut confirmer : écrivez son nom et son numéro. Le concepteur l'appellera.
  5. Touchez Envoyer la demande.

Ensuite : la carte affiche « Demande envoyée le … : en cours d'examen ». Quand le rôle est accordé, l'Espace Directeur s'ouvre avec le nom de votre établissement et cinq onglets.

Vous avez déjà envoyé une demande sans preuve ? Un bouton Compléter ma demande apparaît : ajoutez la photo ou le contact du conseiller, puis Envoyer la preuve. Sans preuve, la demande ne peut pas être examinée.

3. Étape 2 (directeur) : relier les classes de l'école

Au départ, l'Espace Directeur est vide : chaque enseignant doit rattacher sa classe à votre établissement, avec votre accord. Cela se fait en trois temps.

  1. Vous donnez le code de l'établissement. En haut de l'Espace Directeur, sous le nom de l'école, touchez Code de l'établissement. Le code s'affiche, par exemple ABCD-EFGH-12. Donnez-le à vos enseignants (réunion, WhatsApp).
  2. Chaque enseignant envoie une demande depuis son téléphone (voir la partie 7 de ce tutoriel).
  3. Vous confirmez chaque demande. Ouvrez l'onglet Enseignants. Dans « Demandes de rattachement », chaque demande montre l'enseignant, sa classe, son niveau et son effectif. Touchez Confirmer (ou Refuser).

Le nombre de demandes en attente s'affiche aussi à côté du code, par exemple « Code de l'établissement · 2 demande(s) ».

Bon à savoir :

  • Renouveler le code le rend inutilisable : faites-le si le code a circulé hors de l'école.
  • Pour retirer une classe (enseignant parti, erreur) : onglet Enseignants, « Enseignants rattachés », Retirer, avec un motif.
  • Vous tenez aussi une classe ? Touchez Ma classe sous le nom de l'école : rattachez-la avec votre propre code, puis confirmez la demande dans l'onglet Enseignants.

4. Étape 3 (directeur) : lire le tableau de bord

L'onglet Tableau de bord résume toute l'école en un écran. Les chiffres se calculent tout seuls à partir des classes rattachées.

BlocCe qu'il montre
Chiffres clésClasses rattachées, enseignants, élèves, filles / garçons, redoublants, taux de réussite
Répartition par niveauPour chaque niveau : nombre de classes, effectif, filles, garçons, redoublants, réussite
Résultats par niveauLa moyenne de chaque niveau pour la période choisie (une composition, ou l'année)
Suivi de la saisie des notesLes classes dont les notes sont incomplètes ou absentes
AlertesCe qui demande votre attention, par exemple une classe qui n'a pas envoyé ses données depuis longtemps
Dernières données reçuesQuand chaque classe a envoyé ses données pour la dernière fois

Changer de période : choisissez la composition voulue en haut des résultats (Composition 1, 2, 3… ou l'année).

L'onglet Classes liste chaque classe : enseignant, effectif, moyenne, taux de réussite, date des dernières données. Touchez une classe pour voir ses résultats. La carte Comparer les classes les met côte à côte pour une même composition.

Sans connexion ? L'Espace Directeur affiche la dernière copie reçue, avec sa date (« Actualisé le … »). Tirez l'écran vers le bas, ou touchez la flèche en haut, pour actualiser quand le réseau revient.

Certains chiffres sont masqués ? Pour une classe dont l'enseignant n'a pas donné son accord nominatif, vous ne voyez que des chiffres globaux, jamais le nom ni la note d'un élève.

5. Étape 4 (directeur) : viser les journaux de classe

Les enseignants rattachés peuvent soumettre leur journal de classe de la semaine. Vous le visez depuis votre téléphone, sans papier.

  1. Ouvrez l'onglet Journaux. Le nombre de journaux à viser s'affiche dans son nom, par exemple « Journaux (3) ».
  2. Les journaux sont rangés par semaine, par exemple « Semaine 12 · lundi 09/11/2026 », avec le résumé « 1 à viser · 2 visé(s) · 1 non soumis ».
  3. Chaque classe porte une pastille :
PastilleSignification
À viserL'enseignant a soumis son journal : il attend votre visa
ViséVous l'avez visé
À revoirVous avez demandé une correction à l'enseignant
Non soumisL'enseignant n'a rien envoyé cette semaine
  1. Touchez une classe « À viser » : le journal s'ouvre, jour par jour, avec le taux de présence de la semaine et les élèves peu assidus.
  2. En bas de l'écran, touchez Viser si tout est correct, ou À revoir pour demander une correction.

Quand l'enseignant corrige et renvoie son journal, il réapparaît « À viser », avec la mention de la nouvelle version.

6. Étape 5 (directeur) : produire les documents administratifs

Tout se trouve dans l'onglet Documents. Les informations déjà connues (établissement, effectifs, personnel) sont préremplies : vous complétez seulement le reste.

Le rapport mensuel du directeur (fonctionne même sans connexion)

  1. Carte Rapport mensuel du directeur, touchez Ouvrir.
  2. Choisissez le mois. Le rapport s'ouvre avec les effectifs et le personnel déjà remplis depuis les classes rattachées.
  3. Complétez les rubriques. Votre brouillon est enregistré sur le téléphone au fur et à mesure.
  4. Quand tout est prêt, touchez Finaliser. Le rapport ne peut plus être modifié ; une correction reste possible plus tard, avec un motif.
  5. Produisez-le en PDF ou en Word. Les rapports des mois précédents restent dans « Rapports précédents et versions ».

La Fiche 4 (pyramide de l'école)

  • Carte Fiche 4, Ouvrir. Elle est remplie depuis la liste nominative du personnel : classe tenue, effectifs, corps (IO, IA, IAS).
  • Vous complétez ce que l'application ne peut pas savoir (vacation, malades, RPL…), puis vous la produisez en PDF ou Word.

Le PACC (plan d'action du COGES)

  • Carte PACC, Ouvrir. Un modèle est déjà rempli ; modifiez les lignes ou ajoutez-en avec + Ligne.
  • Pour chaque ligne : rubrique, prix unitaire et quantité. Le coût, les sous-totaux, le fonctionnement du bureau COGES (10 % de la subvention) et le reste disponible sont calculés tout seuls.

Les documents envoyés par les enseignants

CarteCe que vous recevez
Documents reçus des enseignantsListes de classe, résultats, statistiques, journaux, répartitions, tableaux récapitulatifs, groupes d'EPS
Liste nominative du personnelLa fiche de chaque enseignant (matricule, emploi, dates, contacts), réunie en une liste ; PDF, Excel ou Word
Bureaux des activitésCoopérative, Culture, Mères-filles : les bureaux envoyés par les responsables

Les documents de l'école entière (PDF ou Excel) : rapport d'effectifs, tableau récapitulatif des classes, statistiques scolaires, rapport consolidé de l'établissement. Choisissez d'abord la période dans « Période des documents » (une composition, ou les résultats annuels).

7. Côté enseignant : rattacher sa classe et envoyer ses documents

Cette partie est pour les enseignants de l'école. Sans elle, le directeur ne voit rien.

A. Rattacher votre classe à l'établissement (une fois par an)

  1. Demandez à votre directeur le code de l'établissement (par exemple ABCD-EFGH-12).
  2. Ouvrez l'Espace Directeur (Accueil → trois points → Espace Directeur).
  3. Dans « Rattacher ma classe à mon établissement », touchez Rattacher une classe.
  4. Choisissez votre Classe. Si la liste est vide, ouvrez d'abord votre classe une fois avec du réseau pour qu'elle soit sauvegardée en ligne.
  5. Tapez le Code de l'établissement, votre Civilité et le Nom montré à la direction.
  6. Lisez ce qui sera partagé, puis cochez J'accepte ce partage avec la direction de l'établissement.
  7. Touchez Envoyer la demande. Le message « la direction doit la confirmer » s'affiche. Quand le directeur confirme, votre classe apparaît dans son Espace Directeur.

Ce que la direction voit, et ce qu'elle ne voit jamais :

La direction peut consulterJamais partagé
Le nom que vous indiquez, le nom et le niveau de la classeContacts des parents
La liste des élèves : nom, prénoms, sexe, redoublementDates et lieux de naissance
Notes, moyennes, rangs et observations des évaluationsNationalité, extrait de naissance, profil des apprenants
La date de la dernière synchronisationPhotos des élèves
Les journaux que vous choisissez d'envoyer (et, si vous les joignez, la présence de la semaine)Registre d'appel jour par jour, fiches de préparation

La direction ne peut modifier ni vos notes ni vos élèves. Vous pouvez retirer votre accord ou quitter l'établissement à tout moment, depuis « Mes rattachements » dans l'Espace Directeur.

B. Envoyer vos documents au directeur

  • Votre journal de classe : dans le Journal de classe, après avoir préparé la semaine, touchez Soumettre à la direction. Le directeur le vise ou le renvoie « À revoir ».
  • Vos résultats : dans votre classe, trois points en haut à droite, puis Envoyer les résultats au directeur (PDF).
  • Vos autres documents (liste, groupes d'EPS, répartition, tableau récapitulatif…) : après les avoir produits, utilisez Envoyer au directeur.
  • Votre fiche du personnel : dans l'Espace Directeur, carte « Liste nominative du personnel », touchez Ma fiche du personnel. Remplissez-la (matricule, emploi, dates, contacts) et envoyez-la : elle rejoint la liste de l'école et la Fiche 4.

8. Questions fréquentes

Je ne vois pas « Espace Directeur » dans le menu.
Connectez-vous une fois à internet : l'entrée apparaît dès que l'application a contacté le serveur. Vous pouvez aussi taper « Directeur » dans la recherche de l'Accueil.

Ma demande de rôle est « en cours d'examen » depuis longtemps.
Vérifiez qu'elle a bien une preuve. Si le bouton Compléter ma demande est affiché, ajoutez la photo de votre avis de nomination ou le contact de votre conseiller pédagogique.

Ma demande a été refusée.
Le motif est affiché dans la carte. Corrigez ce qui est indiqué, puis envoyez une nouvelle demande.

Faut-il payer ?
Si un abonnement d'établissement est demandé, la carte de l'école l'indique en haut de l'Espace Directeur (essai gratuit, dates, jours restants), avec le bouton Demander l'abonnement de l'établissement. Le rapport mensuel reste disponible même sans connexion.

Le code de l'établissement a circulé hors de l'école.
Touchez Code de l'établissement, puis renouvelez-le : l'ancien code ne fonctionne plus. Vous confirmez de toute façon chaque demande.

Un enseignant change d'école.
L'enseignant quitte l'établissement depuis « Mes rattachements » ; le directeur peut aussi retirer la classe (onglet Enseignants, Retirer, avec un motif).

Le directeur peut-il modifier les notes d'une classe ?
Non, jamais. Tout est en lecture seule. Seul l'enseignant modifie ses notes et ses élèves.

Je suis directeur et je tiens aussi une classe.
Touchez Ma classe sous le nom de l'école : rattachez-la avec votre code, puis confirmez la demande dans l'onglet Enseignants.

Une autre question ?
Dans l'application : Réglages → Nous contacter.
