1. En bref

Le Cahier de l'instituteur fonctionne aussi sur ordinateur, dans le navigateur (Chrome ou Edge), à l'adresse app.cahier-de-l-instituteur.com. C'est la même application que sur le téléphone, avec un affichage adapté au grand écran.

Pourquoi l'utiliser sur ordinateur ?

  • un grand écran pour relire et corriger les fiches ;
  • la saisie des notes au clavier, dans un grand tableau ;
  • l'impression directe sur l'imprimante de l'ordinateur ;
  • l'import de la liste des élèves depuis Excel.

Votre compte reste le même : vous reliez l'ordinateur à votre téléphone avec un code (étape 3). Vous retrouvez alors vos classes, vos élèves et votre abonnement.

2. Étape 1 : ouvrir l'application sur l'ordinateur

  1. Sur l'ordinateur, ouvrez Google Chrome ou Microsoft Edge.
  2. Tapez l'adresse app.cahier-de-l-instituteur.com dans la barre d'adresse, puis Entrée.
  3. L'application s'ouvre. Ne créez encore ni classe ni fiche : reliez d'abord l'ordinateur à votre compte (étape 3).

3. Étape 2 : l'installer comme une application (conseillé)

L'installation place une icône sur le bureau : l'application s'ouvre ensuite dans sa propre fenêtre, sans passer par le navigateur.

  1. Dans l'application ouverte sur l'ordinateur, touchez la pastille Installer en bas à droite.
  2. Ou, dans Chrome et Edge : cliquez sur l'icône d'installation à droite de la barre d'adresse.
  3. Confirmez. L'icône du Cahier de l'instituteur apparaît sur le bureau et dans le menu Démarrer.

4. Étape 3 : relier l'ordinateur à votre compte

Il faut les deux appareils : votre téléphone (où se trouve déjà votre compte) et l'ordinateur.

Sur le téléphone :

  1. Ouvrez Réglages (en bas de l'écran), puis Mes appareils.
  2. Dans « Ajouter mon autre appareil », touchez Créer un code.
  3. Un code de 8 caractères s'affiche, par exemple ABCD-EFGH. Il est valable quelques minutes, une seule fois.

Sur l'ordinateur :

  1. Ouvrez Réglages, puis Mes appareils.
  2. Dans « J'ai un code créé sur mon autre appareil », tapez le code.
  3. Cliquez sur Rejoindre mon compte.
  4. Le message « Cet appareil utilise maintenant votre compte. Vos classes vont se charger. » s'affiche.

Important : l'ordinateur doit être vide (aucune classe, aucune fiche) au moment de la liaison. C'est pourquoi il faut relier avant de commencer à travailler.

5. Étape 4 : passer du téléphone à l'ordinateur (Découverte et Pro)

Avec la formule Pro, votre compte est ouvert sur un seul appareil à la fois.

  • Dans Réglages → Mes appareils, l'application indique où votre compte est ouvert : « Votre compte est ouvert sur cet appareil » ou « sur votre autre appareil ».
  • Pour travailler sur l'autre appareil, touchez Utiliser ici sur celui que vous voulez utiliser.
  • Le travail fait hors connexion reste sur chaque appareil et est envoyé dès qu'il reprend le compte.
  • Revenir sur un appareil déjà relié est gratuit. Le nombre de changements d'appareil est limité : l'écran affiche les changements restants.

Avec Pro Max, téléphone et ordinateur fonctionnent en même temps : rien à faire.

6. Se repérer sur l'ordinateur

Sur un grand écran, l'application s'organise autrement :

ZoneCe qu'on y trouve
Menu à gauche (toujours visible)Accueil, Mes fiches, Mes classes, Mes documents ; Préparer (Préparer une fiche, Proposition de sujet, Banque d'exercices) ; Planifier (Emploi du temps, Répartition mensuelle, Journal de classe, Calendrier scolaire) ; Réglages ; Tout le menu
AccueilSur deux colonnes : votre classe du jour à gauche, la gestion quotidienne et les outils à droite
Mes classes et Mes fichesLa liste à gauche, le détail à droite, côte à côte
Saisie des notesUn grand tableau élèves × matières

Raccourcis clavier :

  • dans la saisie des notes : tapez la note puis Entrée pour l'élève suivant, Tab pour la matière suivante ; vider une case efface la note ;
  • Échap : revenir en arrière (fermer le détail, puis la page).

7. Questions fréquentes

Quel navigateur utiliser ?
Google Chrome ou Microsoft Edge, à jour.

Le code est refusé.
Il est valable quelques minutes et une seule fois : créez-en un nouveau sur le téléphone. Vérifiez aussi que l'ordinateur ne contient encore aucune classe ni fiche.

Mes classes n'apparaissent pas sur l'ordinateur.
Vérifiez la connexion internet, puis patientez quelques instants : les classes se chargent après la liaison. Vérifiez dans Mes appareils que le compte est bien ouvert sur l'ordinateur.

Le téléphone dit « Votre compte est ouvert sur votre autre appareil ».
Avec la formule Pro, un seul appareil à la fois : touchez Utiliser ici pour reprendre le compte sur le téléphone.

L'affichage reste comme sur un téléphone.
La disposition « ordinateur » s'active quand la fenêtre est assez large : agrandissez la fenêtre du navigateur.

Puis-je imprimer directement ?
Oui : après Valider la fiche, touchez Imprimer pour envoyer la fiche à l'imprimante de l'ordinateur.

Une autre question ?
Dans l'application : Réglages → Nous contacter.
